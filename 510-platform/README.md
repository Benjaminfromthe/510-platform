# 510 Platform

Welcome to the 510 Platform project! This project is designed to provide professional cleaning services for electronics and furniture. Below is an overview of the project structure and its components.

## Project Structure

```
510-platform
├── app
│   ├── page.tsx          # Main homepage component
│   ├── layout.tsx        # Overall layout structure
│   └── globals.css       # Global CSS styles
├── package.json          # npm configuration file
├── tsconfig.json         # TypeScript configuration file
└── README.md             # Project documentation
```

## Features

- **Homepage**: The main entry point of the application, featuring:
  - A Navbar with the logo "510" and links to Services, Book Now, About, and a Login button.
  - A Hero section with the headline "Professional Cleaning for Electronics & Furniture" and a Call-To-Action button "Book a Service".
  - Three service preview cards for:
    - Electronics Cleaning
    - Furniture Cleaning
    - Deep Clean Package

## Design

- **Color Scheme**:
  - Primary Color: Navy (#0F172A)
  - Accent Color: Blue (#3B82F6)

- **Responsive Design**: The application is fully mobile responsive, utilizing Tailwind CSS for styling.

## Installation

To get started with the project, clone the repository and install the dependencies:

```bash
npm install
```

## Usage

To run the application, use the following command:

```bash
npm start
```
